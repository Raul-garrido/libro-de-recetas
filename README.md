# Libro de recetas — horno de gas tipo Fontana Maestro

Página de una sola pieza (HTML/CSS/JS sin dependencias) con una colección
de recetas pensadas para un horno de gas tipo **Fontana Maestro 60/40**
(horno de cúpula compacto, pensado sobre todo para pizza, pero también
usable para asados, panes y postres): asados y guisos en cazuela de
barro, arroz al horno, y panes/masas/pizza — que es para lo que este tipo
de horno está más diseñado.

Cada ficha incluye ingredientes, pasos, temperatura y tiempo orientativos,
una nota de adaptación específica para este tipo de horno, foto (real
cuando se ha podido verificar una libre de derechos en Wikimedia Commons,
ilustración propia en el resto) y el enlace a la receta original.

## Uso

Abre [index.html](index.html) directamente en el navegador. No necesita
servidor ni conexión: solo las fotos reales (Wikimedia Commons) requieren
red; si no cargan, la ficha muestra automáticamente su ilustración.
