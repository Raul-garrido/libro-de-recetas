// SINCRONIZACIÓN AUTOMATIZADA CON RECARGA FORZOSA async function syncWithDatabase() { if (!confirm("🔄 ¿Deseas sincronizar y actualizar las recetas desde GitHub? La página se recargará automáticamente.")) { return; } // Mostramos un aviso visual rápido de que se está procesando const syncBtn = document.getElementById('syncGithubBtn'); if (syncBtn) { syncBtn.textContent = "⏳ Sincronizando y actualizando..."; syncBtn.disabled = true; } try { // Añadimos marca de tiempo milimétrica para evitar cualquier tipo de caché en iOS o navegadores const response = await fetch('./recetas.json?v=' + Date.now(), { cache: 'no-store', headers: { 'Cache-Control': 'no-cache' } }); if (response.ok) { const jsonData = await response.json(); if (Array.isArray(jsonData)) { // Borramos la base de datos vieja y metemos la nueva const req = indexedDB.deleteDatabase(dbName); req.onsuccess = async () => { await initDB(jsonData); // Forzamos la recarga total de la página (el F5 automático que pedías) window.location.reload(true); }; req.onerror = () => { // Si por lo que sea falla el borrado de la base de datos, forzamos la recarga de todas formas window.location.reload(true); }; } else { alert("El archivo recetas.json de GitHub no tiene una lista válida."); if (syncBtn) { syncBtn.textContent = "🔄 Sincronizar base de datos"; syncBtn.disabled = false; } } } else { alert("No se pudo descargar recetas.json (Código: " + response.status + ")"); if (syncBtn) { syncBtn.textContent = "🔄 Sincronizar base de datos"; syncBtn.disabled = false; } } } catch (err) { alert("Error de conexión al sincronizar: " + err.message); if (syncBtn) { syncBtn.textContent = "🔄 Sincronizar base de datos"; syncBtn.disabled = false; } } }
